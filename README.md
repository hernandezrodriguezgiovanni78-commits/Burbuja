Ordenamiento por Burbuja  

Asignatura: Estructura de Datos - Unidad 5.

Descripción
Programa desarrollado en Java que implementa el algoritmo de ordenamiento por burbuja para ordenar un arreglo de números enteros de menor a mayor.

 Requisitos
- Tener instalado Java JDK.
- Contar con IntelliJ IDEA o un editor compatible con Java.

## Cómo clonar el repositorio
bash
git clone URL_DE_TU_REPOSITORIO


## Cómo ejecutar
1. Abrir el proyecto en IntelliJ IDEA.
2. Entrar a la carpeta src.
3. Abrir el paquete Metodos_de_ordenamiento.
4. Ejecutar el archivo Mainburbuja.java.

## Resultado esperado
text
Arreglo original:
[6, 1, 5, 8, 3, 2, 7, 4]

Arreglo ordenado:
[1, 2, 3, 4, 5, 6, 7, 8]
